# Submission index: Onboarding Copilot (code, paper, figures, results)

**Project:** an embeddable AI onboarding copilot for web apps (SDK + server + demo) and a research study on keeping guidance anchored to the right element after a site is redeployed.

## What is in this repository

| Path | Contents |
|---|---|

| `tests/` | Playwright end-to-end specs (10 files) |
| `docs/`, `README.md`, `plan.md`, `HANDOFF.md` | Architecture, milestone plan, UX design, handoff notes |

## Headline results (see the paper for full tables, intervals, and caveats)

- Synthetic perturbation benchmark (30 real + fixture page states, 8 operators): hand-weighted resolver 72.2% correct vs role+name 66.1%; learned boosted ranker 96.3% vs a Similo-style baseline 93.6%.
- Real before/after data from the Similo replication package (37 sites with identical targets, 548 targets, held-out sites): **joint-assignment ranker 94.0% vs original Similo 90.1% (+4.0 points, 95% CI +0.4 to +8.3)**; with a margin gate, wrong highlights 2.6% vs 9.9%.
- Honest limits: one real dataset; baselines on the synthetic benchmark are our reimplementations; the fresh-site test is tiny; the learned ranker is not yet integrated into the SDK. A broad sweep of other techniques (set-transformer, MLP, embeddings, fly-hash features, graph matching, etc.) did not improve on 94.0% (`paper/similo/NEGATIVE_RESULTS.txt`).

## Not included (and why)

- `node_modules`, build output, `.env` (API key), SQLite databases.
- `paper/corpus/` (MHTML copies of third-party web pages): re-create with `paper/bench/capture.mjs` and `capture2.mjs`.
- The Similo dataset and code (third party): `git clone https://github.com/michelnass/Similo2`, then set `ROOT` in `paper/similo/load_similo.py` to its `WidgetLocator/apps` folder.
- Large intermediate pickles, regenerated by the scripts in `paper/similo/`.
- Unrelated projects that sat in the same working folder are deliberately excluded.

## Run the application

```bash
pnpm install
pnpm dev                                  # backend :8787 + demo :5173
pnpm -r typecheck && pnpm -r test         # 23 shared + 36 server unit tests
cd tests && pnpm exec playwright test     # e2e (needs Playwright browsers; stop pnpm dev first)
```
Optional AI mode: copy `packages/server/.env.example` to `.env` and add a Gemini key; without it the system runs in deterministic mode.
