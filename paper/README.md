# Paper: Resolve, Don't Remember (IEEE conference format)

- `tex/main.tex` + `tex/ref.bib` — the paper (IEEEtran). Build: `cd tex && tectonic main.tex`.
- `tex/macros.tex`, `tex/tab_*.tex` — generated from results by `analysis/gen_tex.py` (never edit by hand).
- `figs/` — vector figures generated by `analysis/figs.py` and `analysis/hero_fig.py`.
- `bench/` — benchmark harness (Playwright + system Chrome). `cp.bundle.js` bundles the real SDK extractor and shared scorer.
- `results/` — raw outcomes (`robustness.jsonl`, 373,100 rows), timing, codec, live-walk data, `summary.json`.
- `corpus/` — MHTML snapshots of the 14 page states (git-ignored: third-party content; re-create with `bench/capture.mjs`).

Reproduce (from `paper/bench`, after `npm i` in `bench/node`):
1. `node capture.mjs` (needs demo on :5181) 2. `node run_bench.mjs` 3. `node eff_snapshots.mjs` 4. `tsx codec_eval.ts`
5. `python3 -I ../analysis/stats.py && python3 -I ../analysis/figs.py && python3 -I ../analysis/gen_tex.py` 6. `cd ../tex && tectonic main.tex`

## v2 learned ranker
`bench/run_bench.mjs` with `COLLECT=1` records candidate features; `analysis/train_rank.py` + `eval_rank.py` train and evaluate the listwise ranker (4-fold by page; leave-one-operator-out). Exported weights: `results/learned_model_ctx.json`. **Not yet integrated into the SDK** (needs the extra locator attributes in extraction).
